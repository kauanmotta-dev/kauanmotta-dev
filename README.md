### 🍔 [DeliveryCore](https://github.com/kauanmotta-dev/Doura-Delivery-Back) &nbsp;·&nbsp; API de marketplace de delivery com foco em segurança financeira

Núcleo de pagamentos de um marketplace: webhook de pagamento com **assinatura HMAC-SHA256 verificada em tempo constante**, idempotência de evento, optimistic locking e máquinas de estado de pedido e pagamento. PIX com confirmação assíncrona e tracking de entrega via WebSocket.
